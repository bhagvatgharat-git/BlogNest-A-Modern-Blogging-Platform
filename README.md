# BlogNest – A Modern Blogging Platform

A full-stack, internship-grade blogging web application built using **Python Flask**, **SQLite**, **Flask-SQLAlchemy**, and a custom **Light Blue & White** modern UI design system.

---

## 🌟 Overview & Key Features

- **Secure Authentication**: User registration, login, logout powered by Flask-Login and Werkzeug password hashing.
- **Blog Post CRUD**: Create, read, update, and delete posts with draft vs. published state control.
- **Rich Interaction**: Commenting system on published posts with authorization rules (authors and post owners can manage comments).
- **Search & Filter**: Real-time multi-field search (title & content) and category-based filtering.
- **Dashboard & Analytics**: Personal author dashboard showing total posts, published articles, drafts, comments, and engagement stats.
- **Author Profiles & Reading Time**: Calculated estimated reading time for each article and public author portfolio pages.
- **Modern UI / UX**: Light Blue & White aesthetic with glassmorphism, micro-animations, responsive layout, and mobile-ready navigation.

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | Python Flask |
| **Database** | SQLite (with Flask-SQLAlchemy ORM) |
| **Authentication** | Flask-Login & Werkzeug |
| **Frontend** | HTML5, CSS3 (Custom Light Blue & White Design System), Vanilla JavaScript |
| **Template Engine** | Jinja2 |

## 🚀 Quick Start Guide

### 1. Clone the repository
```bash
git clone https://github.com/bhagvatgharat-git/BlogNest-A-Modern-Blogging-Platform.git
cd BlogNest-A-Modern-Blogging-Platform
```

### 2. Set up virtual environment
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
python run.py
```
Open your browser at `http://127.0.0.1:5000`.
